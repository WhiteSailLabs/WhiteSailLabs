# FDE Build Lab experiments

These are small, reproducible personal prototypes behind the four case studies on this profile.
They use only Python's standard library. Each folder contains its own data generator or fixtures,
evaluation logic, and a committed `results.json` produced by an actual run.

Run everything from this directory:

```bash
python3 run_all.py
```

The experiments are deliberately narrow. They are evidence of implementation and testing, not
claims of customer deployment or production impact.
